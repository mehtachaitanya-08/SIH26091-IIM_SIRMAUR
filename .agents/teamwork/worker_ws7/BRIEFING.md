- Paired **Gemma 2 9B (Groq)** with **GPT-4o-mini** due to superior Indic tokenization (1.64 tokens/word fertility vs. 2.68 for Llama 3.1, saving 63% cost and 8.7s generation latency).

- Chose **BGE-M3** for hybrid retrieval (dense + lexical sparse + ColBERT) with **pgvector** in PostgreSQL 16, eliminating separate vector database infrastructure.
- Chose **React + Vite + Tailwind PWA** over Flutter Web (190KB initial bundle vs. >2.8MB Wasm bundle) with Workbox v7, Dexie.js (IndexedDB), and Background Sync API.
- Leveraged **PostgreSQL 16 + PostGIS 3.4** for hyper-local spatial queries (`ST_DWithin` for 35km mandi/vendor radius queries executing in <4.5ms).
- Adopted **Meta WhatsApp Cloud API** (₹0.115/service msg) with WebRTC AudioWorklet streaming and Exotel IVR fallback for 2G feature phones.
